## 🚀 Quick Start Guide

### Step 1: Choose Your Template
1. Visit the [CoverPage Generator](https://mostafa-cse.github.io/Coverpage/)
2. Go to Editor page
3. Select your preferred style from the 11 templates

### Step 2: Fill Details
- **Document Type:** Assignment or Lab Report
- **University Info:** Name, Department, Logo, Address
- **Course Details:** Title, Code, Session, Type
- **Student Info:** Name, Roll, Reg No, Year, Semester, Group
- **Teacher Info:** Name, Designation, Department
- **Dates:** Submission date (+ Experiment details for Lab Reports)

### Step 3: Export
- **PDF:** Click "Download PDF" for high-quality file
- **Print:** Click "Print" for direct printing
- **Live Preview:** See real-time A4 preview with scaling

## 💡 Pro Tips

### Logo Guidelines
- **Recommended Size:** 90-120px square
- **Format:** PNG with transparent background preferred
- **Quality:** High resolution (300 DPI for print)
- **Aspect Ratio:** Square or circular logos work best

### Course Code Formatting
- **Standard:** CSE 301, EEE 101, BBA 201
- **With Dash:** CSE-301 (works too)
- **Long Codes:** CSE 301L (Lab), CSE 301T (Theory)

### Session Format Examples
- 2021-22 (recommended)
- 2021-2022
- Spring 2021
- Academic Year 2021-22

### Name Formatting
- Use proper capitalization: "Ahmed Rahman" not "AHMED RAHMAN"
- Include titles for teachers: "Dr. Rahman" or "Prof. Khan"
- Full names preferred over abbreviations

## 🔧 Custom Template Support

### Create Your Own Template
1. Design HTML with Times New Roman font
2. Use `{{placeholder}}` tokens for dynamic data
3. Set page size to 210mm × 297mm
4. Use black ink (#000) on white background (#fff)
5. Import via "Import Template" button

### Available Placeholders
```
{{universityName}}      {{universityDept}}
{{subjectName}}         {{courseCode}}
{{courseType}}          {{session}}
{{studentName}}         {{studentRoll}}
{{studentRegNo}}        {{studentYear}}
{{studentSemester}}     {{groupNo}}
{{teacherName}}         {{teacherDesignation}}
{{teacherDept}}         {{teacherUniversity}}
{{submissionDate}}      {{experimentDate}}
{{experimentNo}}        {{experimentTitle}}
{{docType}}
```
